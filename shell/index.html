Orbit не знает, откуда взять приложение

Оболочка открывает веб-приложение с его собственного домена, а домен в эту сборку не зашит. Укажите его и пересоберите:

ORBIT_DESKTOP_ORIGIN=https://orbit.example pnpm build

Домен должен совпадать с тем, что разрешён в src-tauri/capabilities/main-remote.json, иначе окно откроется без нативных функций — сборка об этом предупредит.

Для разработки запустите orbit-web (pnpm dev) и откройте оболочку без настроек.

Один раз можно проверить и без сборки: ORBIT_DESKTOP_URL=http://localhost:5173 pnpm dev
